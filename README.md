# WidgetHorario
Creacion de un widget para los horarios de 1 DAM haciendo uso de C# y .NET framwork, desarrollado para Windows.
El Widget puede fijarse o desfijarse para estar sobre el resto de ventanas con el botón del pin.
NO se muestra en barra de tareas, sino en el tray de windows como un icono (flechita abajo a la derecha de la barra de tareas).
El icono contiene menú contextual para mostrar o salir.
